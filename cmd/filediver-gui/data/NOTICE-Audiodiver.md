# Subtitle/audio link data

`subtitle_audio_links.json` is a compact derivative of the subtitle-to-voice-line mapping in [Alomare/Audiodiver](https://github.com/Alomare/Audiodiver), revision `0cfab146f4a0d5f603b37367050c1e54324efd8a`; its source data is licensed under MPL-2.0. The map associates localized subtitle string IDs with Wwise Sound object IDs (and a small number of standalone source IDs). Audiodiver documents that these matches use voice transcription and subtitle timing/clip duration, and marks uncertain duplicate-text matches.

See `LICENSE-Audiodiver-MPL-2.0.txt`. The Helldivers 2 game assets themselves are not included.
